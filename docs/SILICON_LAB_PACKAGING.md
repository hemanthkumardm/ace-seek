# 3D Silicon Lab — Packaging Curriculum

Illustrative schematic modes in `web/public/die_viewer_3d.html` (not tapeout GDS).

| Mode | Level | Teaches |
|------|-------|---------|
| **wirebond** | Beginner | Au wires + leadframe / QFN-style; L≈1.2 nH; SSO |
| **flipchip** | Beginner | C4 bumps + UBM pads; L≪0.1 nH |
| **compare** | Beginner | Wirebond vs flip-chip side-by-side |
| **wlcsp** | Intermediate | Wafer-level CSP — bumps on die, minimal body |
| **bga** | Intermediate | Flip-chip die + coarse BGA balls to PCB |
| **fanout** | Intermediate | FOWLP/InFO-style RDL + outer bump ring |
| **interposer** | Advanced | 2.5D Si interposer + HBM + μbumps |
| **all_compare** | Advanced | Gallery of all package layers + comparison table |

Lesson HUD (`#pkgHud`): typical L, pitch, I/O density, cost, use-cases, physics note.
